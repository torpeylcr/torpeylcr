## NZ Agronomy Assistant

A free Progressive Web App for New Zealand farmers built with React + Vite.

**Features:**
- 📷 AI-powered weed/plant identification via camera (Claude vision API)
- 🧪 Fertilizer recommendations from NZ soil test data (Ravensdown / Ballance products)
- 🌾 Crop profiles with soil test targets for 15 NZ crops
- 🛡️ Crop-safe spray grouping — safe / caution / will damage your crop

**Setup:**
```bash
cp .env.example .env   # add your VITE_ANTHROPIC_API_KEY
npm install
npm run dev
```
